# ҚМДБ цифрлық ақпараттық терминалы

Қазақстан мұсылмандары діни басқармасы (ҚМДБ) ғимаратының кіреберісіндегі үлкен сенсорлы экранға (16:9, **1920×1080**) арналған kiosk интерфейсі. Кітапханасыз, құрастыру (build) қажет емес — таза HTML/CSS/JS.

## Беттер

| Файл | Мазмұны |
|------|---------|
| `index.html` | **Басты бет** (`/`): намаз уақыттары, мәзір, жаңалықтар, Бас мүфти. |
| `map.html` | **Интерактивті карта**: Қазақстан мешіттері мен діни оқу орындары. Төменгі жолда «Басты бет» батырмасы бар. |

Басты беттен картаға өту: мәзірдегі «Интерактивті карта» → `map.html`.

## Басты бет құрылымы (`kiosk/`)

```
kiosk/
├── data.js         — барлық деректер: мәзір, жаңалық, намаз уақыты (PrayerService), тілдер (kk/ru/en), иконкалар
├── components.js   — HTML қайтаратын компоненттер: Header, SidePanel, NamazTimesWidget, MainMenuGrid …
├── app.js          — рендер, тіл/тақырып ауыстыру, сағат, намаз санағы, навигация, 1920×1080 масштабтау
└── kiosk.css       — барлық стильдер (жарық және түнгі режим)
assets/             — логотип, фото, артқы фон сызықтары (bg-lines-*.svg), карта суреттері
```

* **Мәзірге бөлім қосу / бет жалғау:** `kiosk/data.js` ішіндегі `MENU` массивінде `route` жолын толтыру жеткілікті.
* **Намаз уақытының нақты API-і:** `PrayerService.get()` функциясын ауыстыру жеткілікті (қазір демо деректер).
* **Тілдер:** KAZ / РУС / ENG; таңдау `localStorage`-та сақталады. **Түнгі / жарық режим** де солай.
* **Болашақ ішкі беттер:** `kiosk.css`-те дайын layout жоқ; басты беттегі `.k-header` + сол панель + контент құрылымын жалғастыруға болады.
* **Idle режимі:** `IDLE_CONFIG` (`data.js`) — әзірге өшірулі, `kiosk:idle` оқиғасы арқылы қосуға болады.

## Диагностика

* `index.html?lite=1` — барлық сәндік анимацияны өшіреді (жыпылықтау/тежелу себебін іздеу үшін).
* `index.html?phase=night|fajr|sunrise|noon|asr|sunset` — намаз блогының аспан фонын мәжбүрлеп көрсетеді.
* Намаз уақыты ұяшығын басу — сол мезгілдің фонын көрсетеді (қайта басу — автомат режим).

## Іске қосу

Кез келген статикалық сервер немесе `index.html`-ді браузерде ашу жеткілікті. Kiosk үшін толық экран режимі ұсынылады (`chrome --kiosk index.html`).
