# Қазақстан мешіттері мен діни оқу орындары — басты бет

Прототип главного экрана интерактивной информационной платформы «ҚАЗАҚСТАН МЕШІТТЕРІ МЕН ДІНИ ОҚУ ОРЫНДАРЫ» для **большого сенсорного экрана (киоск-терминал), 16:9, 1920×1080**.

## 1. Описание

Дизайн-макет одного экрана (не многостраничное приложение). Назначение — поиск и просмотр мечетей и религиозных учебных заведений Казахстана на публичном терминале.

Состав экрана:

- **Шапка** — герб-знак, заголовок платформы, счётчики (мечети / учебные заведения / регионы).
- **Панель поиска и фильтров** — строка поиска + три фильтра: *Өңір* (регион), *Қала / аудан* (город/район), *Нысан түрі* (тип объекта).
- **Левые 2/3** — интерактивная карта Казахстана: фото-маркеры отдельных объектов и круглые кластеры с количеством объектов по городам.
- **Правая 1/3** — список объектов: фотография, название, местоположение, тип, расстояние; чипы-фильтры, пагинация.
- **Подвал** — источник данных и дата обновления.

Стиль: современный премиальный минимализм — белый фон, тёмно-зелёный акцент, мягкие тени, скруглённые карточки, деликатный исламский геометрический орнамент. Присутствуют анимации: последовательное появление блоков, отрисовка контура карты, «поп» маркеров, пульсация кластеров, hover-эффекты.

Интерактив ограничен уровнем макета: выбор карточки в списке и переключение чипов-фильтров работают, остальные элементы — визуальные.

## 2. Структура файлов

```
/
├── README.md                  — этот файл
├── basty-bet.html             — главный и единственный экран прототипа (разметка, стили, скрипты)
├── image-slot.js              — компонент <image-slot>: слоты под фотографии объектов
│                                (можно перетащить своё изображение мышью)
├── _ds/
│   └── industry-…/            — подключаемая дизайн-система (токены, стили)
│       ├── styles.css
│       ├── _ds_bundle.js
│       └── readme.md
└── screenshots/
    └── final.png              — превью готового экрана
```

Ключевой файл — `basty-bet.html`: он самодостаточен, вся вёрстка, CSS и логика карты находятся внутри него.

## 3. Как открыть

1. Распакуйте архив, сохранив структуру папок.
2. Откройте **`basty-bet.html`** двойным щелчком в браузере (Chrome / Edge / Safari, актуальная версия).
3. Локальный сервер **не обязателен** — экран открывается как обычный файл.

Рекомендуется:

- Требуется **интернет-соединение**: шрифты, библиотеки карты и геоданные Казахстана загружаются с CDN. Без сети экран отобразится, но контур карты и маркеры не появятся.
- Макет свёрстан под 1920×1080 и автоматически масштабируется под размер окна — для точного вида откройте браузер в полноэкранном режиме (F11).
- Если нужен полностью офлайн-запуск или сохранение перетащенных фотографий — запустите папку через локальный сервер, например `python -m http.server 8000`, и откройте `http://localhost:8000/basty-bet.html`.

## 4. Технологии

| Технология | Назначение |
| --- | --- |
| HTML5 / CSS3 | Вёрстка, сетка, анимации (`@keyframes`, `transition`) |
| Vanilla JavaScript | Отрисовка карты, генерация списка, интерактив |
| [D3.js 7.9.0](https://d3js.org) | Проекция `geoMercator`, отрисовка географии |
| [topojson-client 3.1.0](https://github.com/topojson/topojson-client) | Разбор TopoJSON-геометрии |
| [world-atlas 2.0.2](https://github.com/topojson/world-atlas) | Реальные границы Казахстана (Natural Earth, public domain) |
| Google Fonts — Oswald, IBM Plex Sans | Типографика с поддержкой кириллицы |
| Дизайн-система Industry | Токены и принципы оформления (адаптированы под зелёный акцент) |
| `image-slot.js` | Слоты под пользовательские фотографии |
